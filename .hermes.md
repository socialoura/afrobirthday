# Contexte projet — AfroBirthday

App Next.js. Les commandes sont en base Postgres (table `orders`), accédées via
`src/lib/db.ts` (`getAllOrders`, type `Order`).

## Champs d'une commande (`Order`)

| Champ | Sens |
|-------|------|
| `id` | identifiant (les 8 premiers caractères = "ID court") |
| `created_at` | date de la commande |
| `status` | statut paiement (`paid` = payée, `canceled`...) |
| `order_status` | statut production (`pending` / `completed` / `cancelled`) |
| `email` | email du client |
| `message` | message du client à intégrer dans la vidéo |
| `music_option` | `custom` = client a fourni SA musique ; sinon = au choix |
| `music_link` | lien musique fourni (si custom) |
| `music_file_url` | fichier MP3 uploadé par le client (si custom) |
| `delivery_method` | `express` ou `standard` |
| `photo_url` | photo fournie |
| `total_usd` / `currency` | montant et devise |
| `payment_provider` | Stripe / PayPal |
| `country` | pays du client |
| `promo_code` / `discount_amount` | code promo et remise |
| `final_video_url` | rempli quand la vidéo finale est livrée |
| `notes` | notes internes |

## Définitions importantes

- **Commande "en attente" (à produire)** : `status == "paid"` ET `order_status`
  ni `completed` ni `cancelled` ET `final_video_url` vide.
- **music_option** : `custom` = le client a fourni sa musique (lien OU fichier).
  Une musique est "fournie" si `music_link` OU `music_file_url` est présent.
  Sinon il nous laisse choisir.
- Les commandes sont triées de la plus récente à la plus ancienne. "La dernière
  commande" / "elle" / "ce client" sans précision = la plus récente.

## Lien upload direct (et recap)

Le lien upload est un lien magique SIGNÉ (token HMAC) — il n'est PAS stocké en
base et tu ne dois JAMAIS le fabriquer ni deviner le token. Pour l'obtenir,
récupère l'ID de la commande puis exécute, depuis la racine du projet :

    node scripts/upload-link.mjs <orderId> [<orderId> ...]

Le script imprime le lien `upload:` et le lien `recap:` de chaque commande.
Relaie-les tels quels. Tu peux passer plusieurs IDs d'un coup. Si le script
renvoie une erreur (ex: ADMIN_TOKEN_SECRET manquant), dis-le — n'invente pas de
lien.
