🚀 ÉTAPES (15-20 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  INSTALLER FFMPEG
   
   Windows:  choco install ffmpeg
   Mac:      brew install ffmpeg
   Linux:    sudo apt install ffmpeg
   
   📖 Détails: INSTALL_FFMPEG.md

2️⃣  CONVERTIR LES VIDÉOS
   
   npm run optimize:videos
   
   Durée: 5-10 minutes
   → Crée backup dans /public/original-videos
   → Génère MP4 optimisés (H.264)
   → Génère WebM (VP9, 30% plus léger)

3️⃣  VÉRIFIER
   
   npm run check:videos
   
   Résultat attendu:
   ✅ All videos are ready!
   📊 Total MP4:  34.20 MB
   📊 Total WebM: 23.50 MB

4️⃣  TESTER EN LOCAL
   
   npm run dev
   
   Vérifier:
   ☑ Vidéo hero charge vite
   ☑ Vidéos showcase lazy load au scroll
   ☑ Pas d'erreur console
   ☑ Lecture fluide mobile

5️⃣  DÉPLOYER
   
   git push origin main
   
   Vercel déploie automatiquement.
   Les .MOV sont exclus (.vercelignore).

❓ PROBLÈMES FRÉQUENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: FFmpeg not found
A: Installer FFmpeg (voir INSTALL_FFMPEG.md)

Q: Vidéo ne se lit pas sur Safari
A: Normal, Safari utilise le fallback MP4 (pas de WebM)

Q: Qualité dégradée
A: Ajuster CRF dans scripts/optimize-videos.js
   (CRF 28 → 23 pour meilleure qualité)

Q: Script échoue
A: Vérifier:
   1. ffmpeg -version fonctionne
   2. Fichiers source existent dans /public
   3. Espace disque ≥ 500 MB
